# MDLutoronto.github.io (retired)

This site has moved. The Map & Data Library (MDL) tutorials now live at:

**https://mdlutoronto.github.io/tutorials-search/**

Every page on this site, including old `/docs/...` links and unknown URLs,
redirects there automatically via
[`jekyll-redirect-from`](https://github.com/jekyll/jekyll-redirect-from).
Each redirect page includes a canonical link, so search engines index the
new portal instead of this site.

The original workshop content (QGIS, ArcGIS Pro/Online, StoryMaps, CHL5431)
is still in the git history. To see it, check out commit `dbe0f8a`.
